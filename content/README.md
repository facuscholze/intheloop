# content/ — DATOS DEL SITIO

Todo lo que se muestra (temas, videos, shows, textos) vive en JSON acá, separado
del diseño. Para sumar algo nuevo: copiá `_TEMPLATE.json` de la carpeta
correspondiente, completalo y dejá el archivo en `media-src/`. Claude Code
(o los scripts `pnpm add:track`, `add:video`, `add:show`) hace el resto.
