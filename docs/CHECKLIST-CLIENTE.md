# Qué hay que conseguir del cliente

## Imprescindible
- [ ] Fotos del artista en alta resolución (hero, retratos, en cabina)
- [ ] Al menos 2–3 temas propios en WAV/MP3 + sus portadas
- [ ] Al menos 2–3 videos (en vivo / aftermovie), idealmente 1080p
- [ ] Confirmar nombres/ciudades dudosos de `content/shows.json` (campo `needsReview`)
- [ ] Confirmar tagline y bio en español (hoy la bio está solo en inglés)

## Muy recomendable
- [ ] Logo de Tommy / In The Loop (SVG o PNG transparente)
- [ ] Colores o referencias visuales que le gusten
- [ ] Press kit / rider técnico (PDF) si existe
- [ ] BPM y tonalidad de cada tema (para el audio reactivo)
- [ ] Permiso/derechos de cualquier audio que se suba (producción propia o autorizado)

## Opcional
- [ ] Sonido de intro/ambiente para la pantalla de entrada
- [ ] Links de Spotify / Beatport / Apple Music
- [ ] Fotos por ciudad para las galerías
- [ ] Próximas fechas confirmadas
